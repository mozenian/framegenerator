🖨 Print Private Server

            

                Untuk tiap cookie: ambil CSRF → buat private server di place-nya
                → keluarkan link ?privateServerLinkCode=…, yang dipakai
                tools rejoiner. Cookie dikirim ke Worker, dipakai sekali, lalu ikut
                hilang — tidak ditulis ke penyimpanan mana pun.
            


            

                URL Worker belum disetel. Deploy worker_printps.js
                ke Cloudflare Workers, lalu isi URL_WORKER di dalam
                berkas ini satu kali sebelum diunggah.
